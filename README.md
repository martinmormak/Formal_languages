Formal Languages – Regex Simulation & Escape Room Style Parser

This project was developed as part of the Formal Languages course.

It is a group assignment focused on building an interactive system that demonstrates key concepts from formal language theory in a practical and engaging way.

The project includes:

Simulation of regular expression processing, showing how regex patterns are evaluated step by step
Implementation of a lexical analyzer, responsible for tokenizing input based on defined rules
Implementation of a syntactic analyzer, which validates structure according to a defined grammar
A custom calculator language, defined by formal rules and processed by the system
A programming-by-definition environment, where programs are created from formal specifications
An “escape room” style structure, where users solve tasks by understanding and applying formal language concepts

The goal of the project was to connect theoretical concepts such as automata, grammars, and parsing with an interactive and visually guided application that helps understand how programming languages and expressions are processed internally.
